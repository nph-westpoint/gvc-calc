# gvc-calc
GVC-Calc was developed to assist researchers with Continuous Glucose Monitoring (CGM) data by West Point's AI Data Engineering and Machine Learning (AIDE-ML) Center. The focus of the tool is to calculate as many glycemic metrics as possible while documenting the choices that were made during the computation of each.

# How to run this App
There are two alternatives to running this app provided for the user. There is a zero-download option that is run on the Streamlit servers, and a second option using a Dockerfile
## Method 1 (Easiest)
The first is just using it on Streamlit's Community Cloud environment which is linked to this Git Repository. The web address for the app is: [GVC Calc](https://gvc-calc.streamlit.app/)
